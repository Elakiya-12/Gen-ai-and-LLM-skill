AI OBJECT DETECTION – PROJECT INFO

Project: AI Object Detection Web App
Main File: obj_detector.py
Tool: Streamlit
Model: facebook/detr-resnet-50

TECHNOLOGIES:
- Python
- Streamlit
- Hugging Face Transformers
- PyTorch
- Torchvision
- Timm
- Pillow

HOW IT WORKS:
1. Run the Streamlit application.
2. Upload an image.
3. DETR model detects objects in the image.
4. Results are displayed in the Streamlit interface.

IMPORTANT FIX:
If this error occurs:

ImportError: cannot import name 'pipeline' from 'transformers'

Run:

python -m pip uninstall -y scikit-learn joblib
python -m pip install --no-cache-dir scikit-learn joblib

Then test:

python -c "from transformers import pipeline; print('PIPELINE WORKS')"

If timm error occurs:

python -m pip install timm
